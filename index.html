About me

Quality is a habit, not a phase

I'm a Software Test Engineer from Bengaluru with an MCA from Visvesvaraya Technological University. I analyse requirements, design test scenarios and test cases, and test web and mobile applications across functional, regression, smoke, sanity, integration and UAT cycles.

Beyond the UI, I check what happens underneath: API request-response behaviour in Postman and data consistency in the database with SQL. I report defects clearly in JIRA, retest fixes and run regression so existing features stay safe.

I'm now building automation skills with Playwright, JavaScript and TypeScript, and exploring how to test Gen AI features such as response validation and prompt-injection scenarios.
